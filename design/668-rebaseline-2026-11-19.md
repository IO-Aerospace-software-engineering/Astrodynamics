### R01. Kernel loading and the first kernel set
**Done.** #697: path registry, paths compared by component. #702: the CLI takes a file or a meta-kernel. #703: a missing path throws `ArgumentException(path)` before any unload, a pool generation counter, deleted binary kernels dropped. #710: SPICE messages on load and unload failures; the writers unload the file they replace.
**Remains.** A repeated load still unloads and reloads (SpiceAPI.cs:628-637) and raises the generation, even on a failed load (`finally` at :609-611). Folder order is `Directory.EnumerateFileSystemEntries` (:798-812), the ext4 hash order. No `string` overloads. `UnloadKernels(null)` returns silently (:1054) while `LoadKernels(null)` throws (:599). get-started lists no kernels. `CosmographiaExporter` loads and unloads through the public API.
**Changes to the design.** .NET only: no `ktotal_c`/`kdata_c` proxy needed. The missing-path exception is `ArgumentException`. The folder-order case is stronger since #755 (ext4 seed).
**Evidence.** SpiceAPI.cs:597-650, :791-812, :1052-1054; CosmographiaExporter.cs:404-417; docs/get-started.md:24-49.

## 4. Structuring choices

Twelve choices that shape several lots. Each is open; the recommendation is given.

1. **Data provider (C9 restated; R02, R04, R25).** A static body keeps the provider of its first read (main's rule). A static `Frame` reads the process provider at each transform, since it caches nothing. A public getter `Configuration.Instance.DataProvider` is added, with no `UseDataProvider` scope in 11.0.0. **Open, recommended:** yes, the three rules in one table of the docs.
2. **Conjunction options (R17; D1.6, D1.7, D1.10).** `ScreeningOptions.Analysis` and `AvoidanceSearchOptions.Analysis` are `ConjunctionAnalysisOptions?` (null = the encounter's), and the four mirrors go: they already break in 11.0.0 (`TimeSpan` to `TimeSpan?`). The HBR has one setting, `Analysis.SecondaryHardBodyRadiusMeters`: a fallback in `Screen`, equal or throw in `Analyze`. `ScreeningOptions.DefaultSecondaryHardBodyRadiusMeters` (shipped in 10.1.0) becomes IOA0001. **Open, recommended:** yes.
3. **Covariance: name and `null` (R06, D4.3).** The name is `CovariancePropagation` everywhere, and `CovariancePropagationOptions.None` is added. In `PropagationOptions`, null = Auto. In `ConjunctionAnalysisOptions`, null means "RTN held" today (29 usages, one tutorial): in 11.0.0 it **throws** in `init`, with a message pointing to `.None`. **Open, recommended:** throw, rather than flip silently to Auto.
4. **Time equality (D3.3).** The key is the TAI tick, as on main; `EqualsExact` and `ExactComparer` become public. **Open, recommended:** yes.
5. **Integrator defaults (R07, D4.1).** `RK78IntegratorOptions.Default` = 1e-9/1e-9 (equal to `new RK78Integrator()`; 1.36 m from Kepler after a LEO day). `VVIntegratorOptions.Step` = 1 s. The SSB cost at 1e-9 and 1e-12 is measured again in the lot. **Open, recommended:** yes.
6. **Output grid when round(L/ΔT) rounds up (R11, C11).** start + i·ΔT, then the window end, merged within ΔT/10, on **every** path, listed under Breaking: only the last output moves. Alternative: on the options entry points only. **Open, recommended:** every path, one rule with `TLEPropagator`.
7. **A second `Propagate()` on the same instance (R08).** It throws `InvalidOperationException` naming `Spacecraft.Propagate`. **Open, recommended:** throw.
8. **Reads outside the data (R09).** The type follows the object: `InvalidOperationException` for a body (#527), `ArgumentOutOfRangeException` for the solution, against a public `Window`. `InterpolateAt` becomes IOA0001 and `GetStateVector` the one reader. **Open, recommended:** yes.
9. **Kernels (R01).** A repeated `LoadKernels` furnishes only the missing files and raises the generation only when it furnished something; `ReloadKernels` is added. The files of a folder load in ordinal order, component by component ("the later file wins"). **Open, recommended:** yes to both.
10. **Errors (R03).** Add `SpiceException : InvalidOperationException` with `ShortMessage` and `LongMessage`. A central body of GM 0 is refused at the start of the propagation (`ArgumentException` naming `BODYnnn_GM` and gm_de440.tpc), while `new CelestialBody(id)` still accepts GM 0. **Open, recommended:** yes.
11. **Engine-less maneuvers (R13).** An old attitude constructor drops the engine it is given: the attitude acts on the propagated spacecraft, and the calls that throw today (#691) start to run. Outside a propagation, an attitude uses the axes of the spacecraft of its last bind. **Open, recommended:** yes.
12. **Body names in the CLI (R29).** Add a `bodn2c_c` proxy behind a public `SpiceApi.TryGetNaifId`. The managed CCSDS table (#679) stays kernel-free, for the readers. The `propagate` defaults (Cd 2.2, RK7(8), NRLMSISE-00, `--atmosphere`) land with the grammar, under one Breaking entry. **Open, recommended:** yes.
