# Tutorials

Step-by-step guides progressing from basic ephemeris queries to advanced mission design and space situational awareness.

Each tutorial is self-contained and includes working code examples. Tutorials are ordered by complexity — start from the top if you are new to the framework.

| Tutorial | Level | Description |
|----------|-------|-------------|
| [Ephemeris Queries](ephemeris-queries.md) | Beginner | Query positions of planets, moons, and spacecraft |
| [Coordinate Conversions](coordinate-conversions.md) | Beginner | Frame transforms and Earth orientation |
| [Orbit Creation](orbit-creation.md) | Beginner | Keplerian, equinoctial, and Cartesian representations |
| [TLE & OMM](tle-and-omm.md) | Beginner | TLE parsing, OMM interchange, and SGP4 propagation |
| [Numerical Propagation](numerical-propagation.md) | Intermediate | High-accuracy orbit propagation with force models |
| [Maneuvers](maneuvers.md) | Intermediate | Impulse maneuvers, attitude control, and maneuver chaining |
| [Geometry & Visibility](geometry-and-visibility.md) | Intermediate | Occultations, eclipses, FOV analysis, and ground tracking |
| [Mission Design](mission-design.md) | Advanced | Lambert transfers, launch windows, and mission scenarios |
| [Conjunction Assessment](conjunction-assessment.md) | Advanced | SSA screening, analysis, avoidance, and CDM export |
| [Monte Carlo](monte-carlo.md) | Advanced | Dispersion analysis with covariance-based sampling |
| [Batch Propagation](batch-propagation.md) | Advanced | Parallel multi-spacecraft propagation |

All tutorials assume SPICE kernels are loaded. See [Quick Start](../get-started.md) for installation and kernel setup.
