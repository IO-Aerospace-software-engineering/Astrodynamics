# Services

The framework is free. IO Aerospace funds its development through services around it.

## Support

An annual agreement with a contractual response time, a named contact, and triage of your issues
ahead of the public backlog. Useful when a mission timeline depends on the library and best-effort
community support is not enough.

## Integration

Hands-on work on your side of the boundary: wiring the framework into an existing ground segment or
analysis pipeline, kernel and data management, performance work on your own scenarios, or building
the mission-specific layer on top of the public API.

## Validation Reports

A written, reproducible comparison of your scenarios against an authoritative reference, with the
residuals, the configuration that produced them, and the conformance cases to keep the result
reproducible over time. Intended for use as review or qualification evidence.

## Hosted MCP Server

A hosted Model Context Protocol server exposing the framework to AI assistants, for conversational
mission analysis: ephemeris queries, orbit construction, propagation and geometry searches driven
from a chat client. This is a paid, subscription product, separate from the library.

## Training

Sessions on the framework itself and on the underlying conventions: SPICE kernels, time systems,
reference frames, and the pitfalls that cost the most time in practice.

## Contact

Through [io-aerospace.org](https://io-aerospace.org/). Describe the mission context and the
constraint you are working against; it makes the first answer a useful one.
