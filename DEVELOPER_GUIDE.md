# IO.Astrodynamics.Net Developer Guide

The developer guide is the documentation site, [docs.io-aerospace.org](https://docs.io-aerospace.org/), built from the
pages of [`docs/`](docs/) in this repository, whose C# examples are compiled and run by the tests. This file held a
single-page copy of the guide up to 10.x; since 11.0.0 each of its former sections is a page of the site:
